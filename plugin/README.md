# Twisted Block (Phase 0 proof of concept)

Tracker grid test for the MPC Live 3. There's no audio yet, so it outputs silence.

Install: copy "Twisted Genetics - VST - Twisted Block" into "VST2 Plugins" on a
drive. Needs MPC OS 3.10.1+, with Preferences > Enhancements (Beta) > Enable
Enhancements and External Plugin Support turned on.

Controls: the first Q-Link bank is Row / Field / Value / Lane. Tap a cell to move
the cursor there; tap L1-L4 to switch lanes. Hold a pad to play the block, or
press Play. Turn on Stress to test redraw speed.

See https://github.com/TwistedGenetics/Twisted-Block for the hardware test checklist.
