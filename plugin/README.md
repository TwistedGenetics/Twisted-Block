# Twisted Block

A sample-based block tracker for the MPC. In Play mode, C1 triggers block 01,
C#1 block 02, and so on. Each block has 4 lanes, there are 16 instruments,
and the tracker has effect commands and slicing.

Install: copy "Twisted Genetics - VST - Twisted Block" into "VST2 Plugins" on a
drive. Needs MPC OS 3.10.1+, with Preferences > Enhancements (Beta) > Enable
Enhancements and External Plugin Support turned on.

Your samples: put WAVs in a folder called "Twisted Block Samples" at the top
of the same drive. Then on the SAMPLE page, pick Inst and File and tap LOAD.

Full guide: https://github.com/TwistedGenetics/Twisted-Block
